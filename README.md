# OPEN Portfolio — handoff for Claude

В папке лежит:
- `assets/open-portfolio-mockup.png` — утверждённый визуальный референс.
- `index.html` — стартовая структура сайта.
- `styles.css` — базовая стилизация и адаптив.
- этот README — ТЗ для доработки.

## Что нужно сделать в Claude
1. Взять `open-portfolio-mockup.png` как главный visual reference.
2. Сохранить визуальную систему: тёмный OPEN hero, белый контент, красный акцент, тонкие линии, крупная типографика.
3. Заменить placeholder в hero на финальную фотографию.
4. Разнести достижения по четырём направлениям:
   - Люди — развитие и ротации;
   - Проекты — достижение ключевых целей;
   - Инструменты — разработанные стандарты и AI-решения;
   - Коллаборации — кросс-функциональные взаимодействия.
5. Каждый кейс должен поддерживать описание, метрики результата, FTE-эффект и вложенные материалы (PDF/PPTX/изображения).
6. Сделать отдельный экран/модальное окно кейса с превью презентации и кнопкой открытия/скачивания документа.
7. Подготовить production-ready адаптивную версию для desktop/mobile.
8. Не выдумывать реальные достижения, цифры и документы: оставить понятные placeholders там, где контент ещё не передан.
9. Подготовить проект к деплою (например, Vite/React или чистый HTML — на усмотрение Claude) и дать инструкцию запуска/сборки.

## Визуальный принцип
Это не классическое резюме. Сайт должен восприниматься как портфолио руководителя: **люди → процессы → результат**, где каждое достижение подтверждается конкретным кейсом и материалами.
